# Company Logos Directory

This directory contains the company logos used in the floating logo strip on the homepage.

## How to Add Your Company Logos:

1. Replace the placeholder image files with your actual company logo PNG files:
   - `company-logo-1.png`
   - `company-logo-2.png`
   - `company-logo-3.png`
   - `company-logo-4.png`
   - `company-logo-5.png`
   - `company-logo-6.png`

2. **Image Specifications:**
   - **Format:** PNG (recommended for transparency)
   - **Size:** 200x100px or similar aspect ratio
   - **Background:** Transparent or white background
   - **Style:** Company logos should be clean and recognizable

3. **File Naming:**
   - Keep the same naming convention: `company-logo-1.png`, `company-logo-2.png`, etc.
   - The logos will appear in numerical order in the scrolling animation

4. **Styling Notes:**
   - Logos are automatically filtered to white (`filter brightness-0 invert`)
   - They are sized to `h-12` (48px height) with auto width
   - Hover effects and glassmorphism styling is applied automatically

## Current Setup:
- 6 logo placeholders in the scrolling animation
- Seamless infinite loop with duplicate set
- 30-second animation cycle
- Responsive design for all screen sizes

Simply drop your PNG logo files into this directory with the correct names, and they'll automatically appear in the floating logo strip!
