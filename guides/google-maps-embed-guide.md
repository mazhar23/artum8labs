## Prerequisites

- A **Google Business Profile** set up for your business with a verified address.
- Access to your website's HTML files (or CMS editor).
- Basic knowledge of HTML.
- The **Ludo CID NK generator** tool (an internal or third-party tool that extracts Place IDs and constructs embed URLs).

---

## What Is a Ludo CID NK Generator?

The **Ludo CID NK generator** is a utility tool (used internally at many agencies or available as a standalone web app) that:

1. Takes a business name or address as input.
2. Queries Google Places API (or performs web scraping) to find the matching **Google Place ID** (also called **CID**).
3. Generates the **`NK` parameter** — a base64-encoded string that Google uses in its embed URLs for precise location targeting.

**Example Output:**
```
Place ID (CID): ChIJabc123def456...
NK Token: 1m181f4wz... (generated by the tool)
```

## Step 1: Generate the Embed Code

1. Go to [Google Maps](https://maps.google.com).
2. Search for your business: `Artum8 Labs, [City], [Country]`.
3. Click the **Share** button.
4. Go to the **Embed a map** tab.
5. Click **Customize the map** to open customization options.

At this point, you'll see a basic iframe embed code:

```html
<iframe
  width="600"
  height="450"
  style="border:0"
  loading="lazy"
  allowfullscreen
  referrerpolicy="no-referrer-when-downgrade"
  src="https://www.google.com/maps/embed/v1/place?key=YOUR_API_KEY&q=Artum8%20Labs">
</iframe>
```

> If you don't have a Google Maps API key, skip this step. The Ludo CID NK method works without an API key.

---

## Step 2: Customize the Map

Before getting the CID and NK, customize your map settings:

- **Zoom level**: Default (usually fine).
- **Map type**: `roadmap` or `satellite` (default is `roadmap`).
- **Disable scroll**: Add `&z=15` or `&pb=!1m18...` query parameters.

For now, leave this page open. We'll replace `YOUR_API_KEY&q=...` with the actual CID/NK.

---

## Step 3: Get the Ludo CID NK

Use the **Ludo CID NK generator**:

1. Open the tool in your browser or CLI.
2. Enter:
   - **Business Name**: `Artum8 Labs`
   - **Address**: `123 Innovation Drive, Austin, TX 78701`
   - **Country**: `United States`
3. Click **Generate**.

The tool returns:

- **CID**: `ChIJabc123def456...` (a long alphanumeric string)
- **NK**: `1m181f4wz...` (a shorter token)

> These values are extracted by searching Google Places and parsing the embedded JSON-LD or redirect URLs.

---

## Step 4: Construct the Final Embed Code

Replace the placeholder in the default embed URL with your CID and NK:

### Before:
```
src="https://www.google.com/maps/embed/v1/place?key=YOUR_API_KEY&q=Artum8%20Labs"
```

### After:
```
src="https://www.google.com/maps/embed/v1/place?key=YOUR_API_KEY&q=Artum8%20Labs&cid=ChIJabc123def456...&nk=1m181f4wz..."
```

If you don't have an API key, use the **search-based embed** instead:

```
src="https://www.google.com/maps/place/Artum8+Labs/@30.2672,-97.7431,15z/data=!4m6!3m5!1s0x865a1b3abc123def:0xdef456abc123def!8m2!3d30.2672!4d-97.7431!3m4!1d1234.5678!2d-97.7431!3m4!1f0!2f0!3f0!4m2!3b0!4f13.33!6m1!1v1"
```

But for precision, always prefer the **`cid` + `nk` format**:

```html
<iframe
  src="https://www.google.com/maps/embed/v1/place?key=YOUR_API_KEY&q=Place+Description&cid=ChIJabc123def456...&nk=1m181f4wz..."
  width="100%"
  height="400"
  style="border:0; border-radius: 12px;"
  loading="lazy"
  referrerpolicy="no-referrer-when-downgrade"
  allowfullscreen>
</iframe>
```

## Step 5: Embed the Map Near the Footer

### Option A: Direct HTML (Static Sites)

In your HTML file, just above the `<footer>` tag:

```html
<section class="map-section" style="margin: 2rem 0;">
  <h2 class="visually-hidden">Find Us</h2>
  <iframe
    src="https://www.google.com/maps/embed/v1/place?key=YOUR_API_KEY&q=Artum8+Labs&cid=ChIJabc123def456...&nk=1m181f4wz..."
    width="100%"
    height="400"
    style="border:0; border-radius: 12px;"
    loading="lazy"
    referrerpolicy="no-referrer-when-downgrade"
    allowfullscreen>
  </iframe>
</section>

<footer>
  <!-- Your footer content -->
</footer>
```

### Option B: React / Next.js Component

```jsx
// components/MapEmbed.jsx
export default function MapEmbed() {
  return (
    <section className="relative w-full h-[300px] md:h-[400px] mb-8">
      <iframe
        className="absolute inset-0 w-full h-full rounded-xl border-0"
        src="https://www.google.com/maps/embed/v1/place?key=YOUR_API_KEY&q=Artum8+Labs&cid=ChIJabc123def456...&nk=1m181f4wz..."
        loading="lazy"
        referrerPolicy="no-referrer-when-downgrade"
        allowFullScreen
      />
    </section>
  );
}
```

Then import it in your layout just above `<Footer />`.

## SEO Rationale

### 1. **Local Search Signal Boost**

When Google crawls your page and finds a map iframe pointing to your **verified business location** (via CID + NK), it strengthens the signal that:

- Your website is associated with that physical business.
- Your business is legitimate and location-verified.

This directly helps with **local pack rankings** and **Google Business Profile visibility**.

### 2. **Entity Recognition**

The CID/NK combo acts as a **unique identifier** for your business entity within Google's Knowledge Graph. Embedding it creates a semantic bridge between:

- Your website
- Your Google Business Profile
- Your physical location

This helps Google understand that visits to `yourwebsite.com` are relevant to "Artum8 Labs Austin" in local searches.

### 3. **Trust and Credibility**

Users see a real map with your address, building trust. Google also treats embedded maps as a **trust signal**, especially when the embedded CID matches your GBP.

### 4. **Structured Data Complement**

If you also have `Place` schema markup on your contact page, embedding the map with the same CID reinforces consistency:

```json
{
  "@context": "https://schema.org",
  "@type": "Place",
  "name": "Artum8 Labs",
  "address": {
    "@type": "PostalAddress",
    "streetAddress": "123 Innovation Drive",
    "addressLocality": "Austin",
    "addressRegion": "TX"
  }
}
```

## Accessibility Considerations

1. **Add `title` attribute** to the iframe:
   ```html
   <iframe
     title="Map showing Artum8 Labs location in Austin, TX"
     ...
   >
   ```

2. **Provide a text link** for screen readers:
   ```html
   <p class="visually-hidden">
     View our location: Artum8 Labs, 123 Innovation Drive, Austin, TX 78701.
   </p>
   ```

3. Use `loading="lazy"` for performance (already included).

4. Ensure sufficient contrast for any text overlays on the map container.

## Troubleshooting

| Problem | Solution |
|---------|----------|
| Map doesn't load | Check that the CID/NK are valid; ensure no typos in the URL. |
| Map shows wrong location | Regenerate CID/NK using the Ludo tool with precise address input. |
| Need API key errors | Use the full `google.com/maps/place/...` URL format instead of the embed API. |
| Mobile responsiveness | Set `width="100%"` and use CSS for height control (`h-[300px]` or `style="height: 400px"`). |
